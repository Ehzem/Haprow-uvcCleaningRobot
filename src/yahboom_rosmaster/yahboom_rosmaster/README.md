# Yahboom ROSMASTER metapackage

This metapackage groups the original ROSMASTER bringup, description, navigation,
localization, docking, Gazebo and system-test packages. The Haprow UVC robot
is described separately in `uvc_robot_description` and is the default robot in
the operating-theatre launch.

Use the [main workspace README](../../../README.md) for the current Ubuntu
24.04/ROS 2 Jazzy setup and Docker team workflow.
